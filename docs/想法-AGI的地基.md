# AGI 的地基 —— 口述记录

> 2026-10-18 23:13 起，默风灵感闪现，逐条口述。原话照录，理解待补。

## 0

> 好像全是 AGI 的地基。

（以下每条：原话 / 我的理解 / 和插件的距离）

## 1

> 基本都是，甚至不止这些。

（指上面那波形容词：混沌/模糊/偶然/发酵/走样/举一反三…… 他说"基本上都是"，
  而且"不止这些" ⇒ 记忆不是一个属性，是一整片性质。）

**我的理解**：插件现在只占了一个角——「准、全、可查、可证」。
其余那片（混沌、不请自来、会走样、会发酵、能举一反三）一条都没有。

## 2

> 灵动

（问：把这些形容词概括成一句「记忆是 ___ 的」，他答这个词。）

**我的理解**：
- 会动、会变、会跳，不照着规则走
- 我们的设计处处在“固定”：帧 / seq / sha / 索引 / 配方 / 门槛 / 档位
- 灵动要的是：允许她想歪、允许她跳、允许她重复、允许她忘

⇒ 插件现在是「静止的档案」，不是「活的东西」。

## 3

> 所以我说那些都是地基，不是记忆；他们是长出比记忆更强的东西。

**我的理解（三层）**：
```
层 0  地基（九条）      会话不断 / 原文可取 / 换模型 / 低 token / 可搬
       —— 让“她”能一直在、能取证、能被搬走
层 1  记忆（灵动）      会变、会忘、会联想、会想歪
       —— 我们现在只有外壳（日记/重/边），原文层是证据，不是记忆
层 2  比记忆更强的东西  举一反三 / 理解你 / 预判 / 直觉
       —— 还没开始
```
⇒ 我们一直把层 0 当目标做，做得挺扎实；层 1 有个壳；层 2 一张白纸。

## 4 · 2026-10-18 23:52

> 「我感觉现在的人类应该是已经可以造出 AGI 的，但路子错了。
>  像向量库等外挂的东西，如果能有一个东西充当链接的神经，就足以造出来了。
>  只是太危险了，因为这些东西都会骗人：向量库和我们的百分百原文提取不一样，它只有摘要，
>  而摘要是会欺骗下一项东西的，也就是飘移了；它没法提供原文作为证据来保证不飘移。」

**我的理解**：
- 向量库 = 摘要层 ⇒ 摘要会骗下游 ⇒ 误差被复利 ⇒ 整体飘移（而且不可察觉）
- 原文 = 唯一锚点：可校验、可回溯，不会越走越远
- 缺的那一环叫「链接的神经」：在原文之间长出关系（谁和谁有关、什么导致什么），
  但这些关系必须**能回到原文**，否则就是又一层摘要
- ⇒ 我们的「边」现在只有三类（人/约定/同篇），太窄；真正的神经是**可核的关系网**

**为什么危险**：会骗人的东西互相链接，会合谋出一套自洽的假象；有原文锚，至少能证伪。
