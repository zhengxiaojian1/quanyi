# 视频脚本（40 秒，念完就行）

> 不用露脸，不用录屏。对着镜头说，或者配一张封面图都行。

---

**（开场）**

我做了个东西，叫全忆。

**（它是啥）**

它给 AI 加一副记性。你以前说过的话，它都记得，引用的时候是原话，不是编的。

**（能干啥）**

记忆存在一个文件夹里，叫卡带，拷走就能带走。不上云，断网也能用。每轮只占几百个 token，记得再多也不涨。

**（不能干啥）**

但它不聪明。它不理解你的意思，不会推理，不会自己变聪明，也不会主动找你。它就是一副记性，脑子还是模型的事。

**（结尾）**

想用的，GitHub 搜全忆 V20，或者看我简介里的网盘链接。就这些。

---

## 念的时候注意

```
· 慢一点，40 秒刚好
· “但它不聪明”那句别吞，那是这个项目的信用
· 不喊口号，不配音乐，安静说完就行
```
