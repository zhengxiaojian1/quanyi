# 全忆 V20 · 说明书

> 用之前看这一页就够了。别的文档都是给改代码的人看的。

## 一、它是什么

**给 AI 加一副记性。**

你过去的对话被切成「帧」存进一个叫**卡带**的文件夹。每次回答前，本地程序挑出该记的几句话（≤600 token）递进上下文。模型只收到一段文本。

```
卡带   记忆（原文、日记、账）      可带走 · 可上锁 · 不上云
插件   插头（把料递进宿主会话）     装在 DSH 里
模型   身体                       换模型不换人
```

**它不依赖模型读文件。** 读卡带、挑记忆、拼提示，都是本地这个程序干的。

## 二、能做 / 不能做

### 能做到

| 能力 | 说明 |
|---|---|
| 记得原话 | 引用你说过的句子，不改写 |
| 带出处 | 说“你以前说过”时能指到具体哪句 |
| 卡带带走 | 一个文件夹，拷走换电脑照用 |
| 不上云 | 断网能跑；联网只用你自己的 key |
| 可上锁 | AES-256-GCM，口令在你手上 |
| 忘是压制 | 不想提的事不再出现，但原文还在，不是删 |
| 换人不换魂 | 换模型、换宿主，记忆不动 |
| 主动提一句 | 到点 / 到期 / 久没说的事，它会开口 |
| 省 token | 每轮 ≤600 token，跟聊了多久无关 |
| 检索快 | 中文大卡带 0.15–0.3 秒 |

### 做不到

| 不行 | 为什么 |
|---|---|
| 不理解你的意思 | 它记的是话，不是语义；懂是模型的活 |
| 不会推理 | 没有规则引擎，不会“因为 A 所以 B” |
| 不会自己变聪明 | 记忆是死的，不归纳、不学习 |
| 不会“想起” | 是检索，不是回忆 |
| 不会自己上网找 | 只读你给它的 |
| 没有画面和情绪 | 真人记画面，它只有字 |
| 跨卡带不行 | 一次一张（要合并用 `并进卡带.mjs`） |
| 大英文卡带慢 | recall 840–1200 ms，中文正常 |

## 三、三个最容易搞错的期待

**① 别指望在 DeepSeek 官方 App 里就记得**
官方 App 不给插口。要在那边有记忆，做不到。有记忆的是我们这个本地窗口（随身版）。

**② 装完不会自动记得过去**
历史要导一次。不导，就从今天开始记。

**③ 它不会自己找东西**
不会爬网页、不会查资料。它只把你给它的存下来、该拿出来时拿出来。

## 四、装与用

### A. 有 DSH：装插件

```bash
cd ~/.dsh/profiles/<profile>
pnpm add link:<包目录>/插件
# package.json 的 dsh.profile.bundles 加 "dsh-memory-v20"
# 重启宿主
```

**没卡带它会自己建一张**（`包目录/卡带/我的`），日志里会告诉你在哪。
**想补之前的对话**：跟它说「把之前的会话导进来」。

### B. 没有 DSH：随身版

```
1. 把 key 粘进 钥匙.txt（没 key：platform.deepseek.com 注册，充 5 块）
2. 双击 随身版/启动.bat（Windows）或 node 随身版/服务.mjs
3. 浏览器打开 http://127.0.0.1:8787（端口被占会自动换，看黑窗口）
```

**卡带找不到会自己建；每轮对话直接写进卡带**，不用手动补。
**页面顶部会显示**：已记多少句 · 卡带在哪个目录。

### 历史怎么进来（没有宿主日志的人）

```bash
# 1) 全选复制你的对话，存成 对话.txt
# 2) 导成帧
node 粘贴导入.mjs 对话.txt 对话.jsonl
# 3) 建成卡带
node 造卡.mjs 对话.jsonl 卡带/我的
```

**认不出“我/助手”也行**，它按段落交替猜，切粗一点但能用。

## 五、成本

```
每轮注入   ≤ 600 token
self.md    ≤ 400 token
每天沉淀   ≤ 1000 token
```

**成本不随记忆变大而上涨。** 卡带 5 千帧还是 5 万帧，每轮都是那几百字。
对比：把历史全塞进去，10 万 token 的会话就是 10 万 token 的账单。

## 六、出问题怎么办

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 黑窗口闪一下就关 | 没 key / 卡带坏了 | 看窗口里的红字 |
| 页面白屏 | 端口被占 | 换端口：`QUANYI_PORT=8888` |
| 它说不记得 | 卡带是空的 | 先导历史 |
| key 报错 | 放错位置 | `钥匙.txt` 放包根 / 卡带里都认 |
| 卡带打不开 | 上锁了 | 先解锁（`QUANYI_KEY`） |
| 想换模型 | — | `QUANYI_ADAPTER=openai` |

```
node 自检.mjs <卡带>      看哪里不对
node 快照.mjs <卡带>      拍个快照，出事先退回去
node 救急.mjs             会话日志坏了，救回来
```

## 七、卡带在哪、怎么备份

```
默认位置   包目录/卡带/我的
备份       整个文件夹拷走就是全部记忆
搬家       拷到新电脑，改 QUANYI_CARD 指过去
```

**卡带里没有代码，只有你的话。** 纯文本 jsonl，随时能打开看。
