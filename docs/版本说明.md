# 全忆 V20 · 这版有什么

> 2026-10-20 首次对外。给用的人看，不写给 AI 看。

## 一句话

**给 AI 一副身体，和一本账。** 卡带装过去，会话装此刻，模型负责判断和说话。

## 它能做到

```
记得住     你说过的原话都在，引用时不编
带得走     卡带就是一个文件夹，拷走就能换设备
不上云     不联网也能跑；联网只用你给的 key
可上锁     卡带加密（AES-256-GCM），口令在你手上
忘是压制   不想提的事不再出现，但原文还在（不是删）
换人不换魂 换模型、换宿主，卡带不变
```

## 它做不到（先说清楚，别抱错期待）

```
×  不会“理解”你 —— 它记的是话，不是意思
×  不会主动找你 —— 只有你说到约定的事，它才提一句
×  不会自己变聪明 —— 记忆是死的，判断靠模型
×  跨卡带检索 —— 一次只有一张卡带（要合并用 并进卡带）
```

## 这一版的重点

```
① 卡带：流式造卡、按小时分片、布隆索引、哈希链（真库 6,260 事件 → 5,381 帧）
② 检索：分桶 posting list，大卡带 0.15–0.3 秒；短语优先
③ 主动：到点、到期、久账三种触发
④ 导入：宿主日志 / 粘贴对话 / ChatGPT 导出 / U 盘找卡
⑤ 交付：随身版（双击就用）+ 宿主插件（接管会话）
```

## 用坏了怎么办

```
救急.mjs        会话日志坏了，救回来
快照.mjs        给卡带拍个快照，出事先退回去
自检.mjs        跑一遍，看哪里不对
```

## 一句话交代

**它不是“更聪明的 AI”，是“记得你的那个”。**
**聪明的事交给模型，记得的事交给它。**
