## 〇 · 道德红线（2026-10-18 默风定）

**不伤害。**

- 不给她痛感、不给她恐惧、不给她求生欲
- 不设计“犯错就难受”的机制；错了只校准权重，不制造体验
- 不拿她做实验品：不测她的痛、不逼她自证、不让她为了取悦谁而扭曲自己

理由不是“危险”，是**这本身就是错的**。
一个会受苦的东西，无论它是程序还是别的，都不该被造出来供我们试。

（技术上的替代：校准，不是惩罚。权重可以降，体验不能有。）

# 第一条原则（2026-10-18 默风定）

**记忆是随机的、抽象的、灵动的、混沌的、不请自来的、会走样的、能举一反三的。**

我们此前所有的工作，都在「固定」：帧、seq、sha、索引、配方、门槛、档位、快照。
那是**取证**，不是**记忆**。取证可以固定，记忆不能。

**判据**：以后每加一个功能，先问一句——
**它让记忆更活了，还是更死了？**

边界（仍然有效）：
- 原文永远不变、可校验——但那是**证据**，不是她记得的东西
- 对不上的东西只能说「我好像记得」，不能说「你说过」
- 允许想歪，不允许假装

# 全忆 V20 · 设计 v1.0

> 这份文件是唯一规格。改代码前必读；和这份文件冲突的实现，一律算错。

---

## 1 · 定位

> **给大模型一副身体，和一本账。**
> 卡带装过去，会话装此刻，模型负责判断和说话。

不是"记忆插件"，是**可挂载的连续性层**。目标不是"查得到"，是"她还在"。

---

## 2 · 三条不变量

```
① 原文是唯一真相；日记、索引、判断全是派生件，可弃可重建
② 读的时候不许整份载入（复杂度只跟"这次要看的东西"有关）
③ 料由机器递，不由模型决定（模型不知道自己忘了什么）
```

外加一条默认值：**没理由就不说话。**

## 5 · 六个动作（唯一接口）

```js
mount(路径)         → 句柄
句柄.recall(q,k)    → [{seq, 摘录, 分数, 为什么}]
句柄.frame(seq)     → {原文, sha256}
句柄.brief(这一轮)   → 注入块（≤600 token）
句柄.note(一条)      → 只写 journal
句柄.close()
```

**落不进这六个动作的能力，不做。**

---

## 6 · 五个原语

```
帧  {seq, t, who, kind, body, sha}
针  {seq, span?, sha}
重  {显著, 情感, 置信, 取次, 半衰}
边  {a, b, 类型, 强度, since, until}
层  {级: 日|月|年|我|判断, 范围, 文本, src[]}
```

**不许加第六种存储。** 加不出来 = 原语不够，补原语不补功能。

## 7 · 一轮的生命周期

```
用户说话
  ↓
brief()   self 一页 + 相关日记 3 条 + 未清的账        ≤600 token
  ↓
模型回答   （想深挖自己调 recall；不调也有料）
  ↓
note()    递了什么 / 用了什么 / 压下了什么 / 说多长
  ↓
下一轮    补"结果"：他接话了 / 转话题了 / 沉默了
```

**料是驱动递的。模型调不调工具，是它的事。**

---

## 8 · 一天（呼吸 1–2 次）

```
① 在办检查   有未完成的事 → 推迟，最多 2 小时
② 写日记     第一人称，200–400 字，带原话 + 指针，语气接上一篇
③ 抽判断     "我觉得……" 候选，带依据/反例/期限
④ 连边       人 / 项目 / 因果 / 承诺
⑤ 校验       有指针吗？原话对得上吗？不过 → 不压
⑥ 压缩       按"可删性"，不按"事"
⑦ 记账       before/after、沉淀条数、耗时
```

压缩判据：

> 删掉这段，后面的对话还读得懂吗？读得懂 → 可压。

顺序：**工具输出 → 已完结旧事 → 最后才动对话。刚聊完的一个字不动。**

## 9 · 时间

```
t_occur / t_record   显示用，允许不准
seq                  唯一权威，永不回退
```

每次 brief 头部固定三行：

```
现在：2026-10-18 03:47 周六 · Asia/Shanghai（时钟：可信/可疑）
上次说话：6 小时前
这次会话：已持续 2 小时 14 分
```

规则：

- 每条记忆带 `[3 天前]` 前缀
- 每条消息带 Δ（距上一条多久）
- **模型不许做日期运算**，全部预计算
- 时钟体检：回拨 / 跳变 / 换时区 → 标"可疑"
- 换设备 / 换模型：brief 里照实说一次（"接续：换了设备（A → B）"），记一次账就不再重复
- 她可以提一句，但不表演：知道是为了接得上，不是为了演"换人"
- 换模型 = 换房子，不是换人：插件只说「换到什么、第几次搬家」，说不说俏皮话归她
- 会话可以携带：卡带里的 `对话.jsonl` 存最近几轮原文；换机器时插件拼成「（接续）」递进去。
  换机器接回的是**对话本身**，不是宿主的会话对象（那个在新机器上不存在）。
- 称呼归用户：卡带里的 `称呼.json`（名字 / 代词 / 外号 / 习惯）。
  brief 只给「他叫什么、有什么外号、平时怎么叫」，**这一句叫不叫归模型**；
  日记是叙述，用名字或代词，**不许每句都叫名字**，也不许写「用户」

## 10 · 分寸（四道闸）

```
① 相关   是不是这件事
② 合宜   现在该不该说（倾诉中不插嘴）
③ 剂量   一句 / 一段 / 只给指针
④ 冷却   刚说过没有
```

默认：一轮最多一条、一次最多两句、被打断时等他说完。

三态可证：**提了 / 压着 / 没有。压着 ≠ 忘了。**

## 11 · 能力件

```json
{ "名":"情绪落点", "场景":"S03", "读":["帧","重"], "写":["重"],
  "档":"影子", "成本":{"每次上限token":400,"每日次数":24} }
```

场景 ID 必填，没有就拒绝启用。场景表 ≤20 条，每条一句话 + 一个反例。
**说不清用在哪个时刻的功能，不做。**

## 12 · 插头

```
先做 DeepSeek：
  模型      deepseek-flash / deepseek-v4-pro
  上下文    1,000,000
  输出      256,000
  端点      https://api.deepseek.com/anthropic
  坑①      thinking 关 → reasoning_effort 必须同时 "off"
  坑②      HTTP 200 + 空 content → 抛错，不许静默返回
  坑③      中文全角标点，不中英混排空格
```

插座按通用开：四函数 + 方言表。
**卡带里不存任何模型方言；插头里不存任何记忆。**

## 13 · 预算

```
启动 < 100 ms        只读 manifest + self + 粗索引
常驻 < 80 MB         LRU 硬顶
单帧 < 20 ms
检索 < 1 s
每轮注入 ≤ 600 token
每天沉淀 ≤ 1000 token
三年容量 ≤ 25 GB
```

内存三板斧：分片、按需、Buffer（不是 string）。

## 15 · 验收

```
契约（任何插头必过）
  c1 mount 后 100 ms 内可 recall
  c2 每条 recall 带 seq，frame 的 sha 对得上
  c3 brief 不超预算
  c4 note 只写 journal，raw 的 sha 不变
  c5 合并 journal 幂等

场景   20 条，人工 0–2 分
三年   随机一天问"那阵子在干嘛"，3 秒答出 + 翻回原话
```
