## 四、功能面

**插件**：每轮 ≤600 token 的 brief、分寸三段、请求侧整形（丢宿主摘要、换她的日记原文、每步都收）、`recall`/`frame`/`forget` 三个工具、接续行、接回 20 轮、起名、标签钉死、宿主日志整份导入、语义改写。

**卡带**：五原语（帧/针/层/重/边）、事实路由（约定/建议）、到点（条件+日期）、久账、压制（不提，不是删除）、加密、多卡、重建、导出、U 盘自带工具链。

**配方机**：能力 = 原语 + 固定算子（最早/最近/变了没/多久没提/谁说过/计数/趋势/时间线/两件事比）；配方从卡带 `配方/*.json` 加载，换卡带就换一套能力。**模型可用 `compose` 工具自己写配方，下一轮生效。**

**迁移**：v19 真库 6,260 事件 → 4,788 帧（跳过 1,400+ 系统注入与重复）。

## 七、边界（照实）

- **网页版聊天框装不了插件**；保底是 `读我.mjs 带话` 生成可粘贴上下文
- **Windows 网吧**：自带 node.exe（83 MB）+ 双击即聊；`/data/data` 的 App 数据读不到
- **v19 存的是摘要**，迁移保留摘要，原文仍在 session-archive
- **换厂商要各家 key**；协议通用，钥匙不通用
- **“一年后还记得我”** 只能靠时间证
