# 上手：十五分钟，让 AI 开始记得你

> 全忆 V20。你要准备两样：**Node ≥ 18**，和 **一个 API key**（DeepSeek 各版本模型都行，key 通用）。
>
> **用「完整版」包的话，Node 已经带在 随身版/node/ 里了，Windows 双击就能跑，不用另装。**

---

## 先看你在哪一条路

```
你平时用 DSH（有 ~/.dsh 目录）       → 走 A，装插件，它能接管你的会话
你平时只用 DeepSeek 网页/App         → 走 B，解压双击，有个记得你的聊天窗
```

---

# A · 有 DSH：装插件（装完自动补历史）

```bash
# 1) 解压交付包到 /root/
cd /root && tar xzf 全忆-V20-交付-*.tar.gz && cd 全忆-V20-交付-*

# 2) 建一个测试 profile（别装在正在跑的那个上）
mkdir -p ~/.dsh/profiles/记忆测试 && cd ~/.dsh/profiles/记忆测试
[ -f package.json ] || echo '{"name":"记忆测试","version":"0.0.1"}' > package.json
pnpm add link:/root/全忆-V20-交付-*/插件

# 3) 在 package.json 里加一行（bundles 里加 "dsh-memory-v20"）
# 4) 把 卡带 路径写进环境变量，或改 插件/cordis.patch.yml
export QUANYI_CARD=/root/卡带/我的

# 5) 重启宿主，用这个 profile 开一次
```

**第一次跑，它会自己把之前的会话切进卡带**（读取器 + 从宿主导入）。

**验证：** 跟它说一句“你还记得我们昨天聊什么吗”，它答得出具体的事，就成。

---

# B · 没有 DSH：随身版

```bash
# 1) 解压交付包
# 2) 进 随身版/ 目录
# 3) 把 API key 粘进 钥匙.txt（包里已经有；没 key 去 platform.deepseek.com 充 5 块就有）
# 4) 双击 启动.bat（Windows）/ 或：node 服务.mjs（Mac/Linux）
# 5) 浏览器打开 http://127.0.0.1:8787
```

**它是个“记得你的聊天窗”，不像插件那样接管宿主，但零配置。**

**卡带会自动找，找不到就自己建一张**（在 包目录/卡带/我的）。
**端口被占会自动换**，控制台会打印新的地址。

## 你的历史怎么进去（B 路必做一次）

DeepSeek 的 App 不能导出，所以用“粘贴”：

```bash
# 1) 打开你的对话，全选复制，存成 对话.txt（内容长这样就行）：
#    我：你还记得桌宠那事吗
#    助手：记得一点，你卡在 2D 的极限上

# 2) 导成帧
node 粘贴导入.mjs 对话.txt 对话.jsonl

# 3) 建成卡带
node 造卡.mjs 对话.jsonl 卡带/我的

# 4) 把 钥匙.txt 放进 卡带/我的/，再双击 启动.bat
```

**认不出“我/助手”也行**——它会按段落交替猜，切粗一点，但能用。
