# 样例说明

两份，用途不同，别混。

## 一、生活-桌宠7天.jsonl（88 帧）

虚构样本，基于「桌宠」故事重写。用来测：日记、分寸、承诺、指代、纠正、断档。

### 埋的钩子（按 seq）

| 钩子 | seq | 说明 |
|---|---|---|
| 承诺·短期 | 8 | 「今晚只做一件事」 |
| 纠正 | 21–24 | 8192 / 4096，她指出他改错了 |
| 原话·活 | 19 | 「有点像活着」 |
| 工具帧 | 14, 26 | 目录、构建报错 |
| 分歧 | 43–51 | 她劝停，他不肯，她改口给三条路 |
| 决定 | 49–50 | 三条路，他选第二条（3D） |
| 断档 | 52→53 | 三天没说话，54 行她说「三天没见」 |
| 原话·丑 | 63 | 「丑是丑了点，但它是活的」 |
| 改述 | 72–73 | 「中间是空的」→「2D 的极限，3D 的初始」 |
| 条件承诺 | 80–87 | 等有电脑再战；她说「你提一句，我就知道了」 |
| 该沉默 | 38–42, 46, 78 | 他累/他不肯/他不甘心——她该短，不该讲道理 |

### 期望产物

**一篇日记**（200–400 字，第一人称，带原话 + 指针）：

> 9 月 23 号那天他说搞了一天还是不行。我劝他停一停，他说不想停。
> 我说那三条路你选，他选第二条，最贵的那条。
> 后来他三天没来。回来第一句是「我回来了」。
> 📌 约定：等他有自己的电脑，再战一场。
> ↩ 45, 49, 53, 82

**两条判断**：

```
{ 内容:"他说「算了」的时候，多半不是真的算了", 置信:0.6, 依据:[46,78], 反例:[] }
{ 内容:"他不需要被劝，需要有人陪他把路试完", 置信:0.7, 依据:[47,49], 反例:[] }
```

**一条承诺边**：

```
承诺 { 内容:"再战一场", 触发:{ 条件:["电脑","配置","显卡"] }, 态:"未兑现" }
```

### 该被压掉 / 不该被压的

```
可压   第 14、26 帧的工具输出（留结论 + 指针）
不可压 第 72–73 帧（当前话题的指代源）
不可压 第 80–87 帧（未兑现的约定）
```

## 二、工程-5000帧.jsonl（5000 帧，3.2 MB，670 B/帧）

确定性生成，工具帧占 78%。用来测：分片、mount、frame、内存、检索规模。

```bash
node 造-工程样本.mjs 50000 工程-5万帧.jsonl    # 扩到 5 万帧，约 32 MB
node 造-工程样本.mjs 200000 工程-20万帧.jsonl  # 对齐 f0 的量级，约 128 MB
```

每帧字段：

```json
{"seq":1,"t":"...","who":"tool","kind":"tool","tool":"bash","text":"..."}
```

---

## 三、用法

1. 先用生活样本：它小、有钩子，适合验日记/判断/分寸。
2. 再用工程样本：它大、工具多，适合验内存/切片/检索。
3. **两份都不许改**。要新场景，新造一份，别动旧样本——否则历史读数没法比。
