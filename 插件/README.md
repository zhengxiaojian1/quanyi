# 全忆 V20 宿主插件（只读）

把卡带的 brief 每轮递进上下文。**不改会话、不写卡带、不做判断。**

## 装法

```bash
# 1) 把插件目录放进一个 profile 的依赖里
cd ~/.dsh/profiles/<你的 profile>
pnpm add link:/root/全忆-V20/插件

# 2) 在该 profile 的 package.json 的 dsh.profile.bundles 里加 "dsh-memory-v20"
# 3) 改 插件/cordis.patch.yml 里的卡带路径（或设 QUANYI_CARD）
# 4) 重启宿主
```

⚠️ 会重启宿主，**别装在正在跑的那个 profile 上**；先开一个测试 profile。

## U 盘

没设 `QUANYI_CARD` 时，插件会在 `/sdcard` `/media` `/mnt` `/run/media` `/Volumes` `/storage` 里找带 `manifest.json` 的目录。
找到一张就用；找到多张会报警并让你设 `QUANYI_CARD`。

## 五个工具

| 工具 | 干什么 |
|---|---|
| `recall` | 翻记忆：按词找说过的话，返回带 seq 的摘录。**他说起过去、你拿不准、要引原话时先用它** |
| `frame` | 取原文：按 seq 取回逐字原文 + sha256。recall 之后要引用或核对时用 |
| `forget` | 他说「别提了」：把某几帧压到最底下（不提，不删） |
| `compose` | 用现有算子给自己加一个能力 |
| `new_card` | 生成一张新卡带 |

## 上下文整形

宿主有没有自动压缩都能用：请求超过 `窗口预算`（默认 60000 token）时，保留最近 `留最近` 条原文，更老的换成一块「（她记得）…」——**这一块用的是她最近 1–3 篇日记的原文**（按丢掉的条数取，上限 600 字），不是模板。
宿主的压缩摘要（`<compacted-summary>` / `automatically generated checkpoint`）会被**丢掉**，换成她的日记块——请求里只有一套叙事。
**只改请求，不动宿主日志**；原文仍在卡带和会话日志里，可 recall 取回。

## 起名

- 新会话（消息很少）且卡带里没有她的名字 ⇒ 注入里带一句「你还没有名字，可以问一句」
- 你在宿主里改了会话标题（source=user）⇒ 插件把它存成她的名字，之后一直用
- 卡带里已有名字 ⇒ 每次接入都钉回这个名字（跨模型、跨宿主）

名字存在卡带的 `称呼.json` 的 `她的名字` 字段。

## 导入已有会话

读取器在插件侧（`读取器.mjs`），一个入口吃 DSH 日志 / Markdown 导出 / 通用 JSON / JSONL / ChatGPT 导出。别的宿主只要能给出会话文件路径，就能接。

卡带是空的 ⇒ 插件先找宿主会话日志（`~/.dsh/sessions/.../session.v4.jsonl.zstd`），**整份**导进卡带（多帧 zstd 逐帧解、只取真正的对话）。
找不到日志时才退回「切上下文窗口」。两种情况都在后台自动跑，你不需要导出、也不需要敲命令。

局限：只能切「插件看得到的上下文」，不是宿主的完整历史；卡带已有历史时不能直接插。

## 会话标签

第一次接入时调宿主的 `sessionTitle.rename()`，把标签钉成卡带里的名字（默认「她 · 默风」）。
用户来源的标题会**钉住**会话，后续自动生成不会再改它。
宿主没挂 `sessionTitle` 服务时，只提示一句，标签保持自动生成。

## 补丁形态（重要）

`cordis.patch.yml` 必须是 **insert + name**：

```yaml
- insert:
    - id: memory-v20
      name: 'dsh-memory-v20'
      config:
        预算: 600
```

只写 `- id: memory-v20` 的补丁不会插入任何东西——宿主会 warn 一句 `entry not found` 然后跳过，
重启后插件是哑的。

路径不用写死：不写 `家` 就按插件自身位置推，不写 `卡带` 就默认 `<家>/卡带样例/桌宠`。

## 工具重名

如果宿主里已经有别的插件注册了 `recall`（比如 v19），会依次尝试
`recall → memory_recall`、`frame → memory_frame`，两个各自独立注册，互不拖累。

## 它做什么

```
每轮第一步 → 取卡带的 brief（≤600 token）→ 追加成一条 user 消息
会话开始   → 记下会话号（同一设备+模型下次建议恢复）
换机器     → 从卡带的 对话.jsonl 取最近 4 轮，拼成「（接续）你们上次停在这里」
每轮结束   → 把这一轮的他/她写进 对话.jsonl（纯文本，跟着 U 盘走）
出任何错   → 只报警，不影响这一轮
```

## 它不做什么

- 不创建会话（会话是宿主的对象）
- 不写卡带（只读）
- 工具注册不是“必然成功”：撞名会退到 memory_*，失败只影响那一个工具，其余照常
